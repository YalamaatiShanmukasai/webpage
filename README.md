# CodeVexa — AI Coding & Learning Platform

CodeVexa is a real-world coding education platform combining structured courses, competitive programming, gamified RPG learning, semantic code validation, code visualization, and AI tutoring.

## Current release
Phase 1 focuses on the course-learning foundation for:
- C Programming
- Java Programming
- Python Programming

Each track contains modules, lessons, examples, practice tasks, quizzes, projects, and progression metadata.

## Product roadmap
- Course learning
- Code Arena
- Real code execution
- Semantic validator
- Code visualizer
- RPG quests, XP, health, coins and badges
- AI Tutor
- Leaderboards and profiles

## Semantic validation example
A requirement such as "assign 3 to a variable" should accept:
- coin = 3
- a = 3
- x = 3

The validator checks program structure/meaning rather than requiring one exact variable name.
